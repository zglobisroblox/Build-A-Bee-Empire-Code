# Ant-game 2D interface spec for the bee restyle

## 0. Conventions and confidence

- **Units.** `sw` / `sh` are fractions of the game viewport width / height. The viewport in the shots is about 726x798 (aspect about 0.91, portrait-ish).
- **Accuracy.** Positions were measured on enlarged crops. Colours were sampled from JPEGs, so treat RGB as +/-10 per channel.
- **Font.** One heavy rounded sans everywhere, which looks like FredokaOne. The only exception is the press-E prompts, which use Roblox's default prompt font.
- **Text rule.** Almost every label is white or a bright colour with a near-black outline (about (10,15,5) to (30,30,30)) and no background plate. Outline is about 2-3 px at 800 px tall on big text and about 1-1.5 px on tiny text.
- **Not game art.** The top-left system buttons (logo, menu, chat, mic) are Roblox's own. The bottom hotbar looks like Roblox's built-in tool bar.
- Anything marked **(guess)** is inferred; **(unreadable)** means too small to read.

## 2. Windows

### 2.1 Shared anatomy

- **Placement and size**
  - Centred horizontally; vertical centre about 46-52% sh.
  - Width about 46-47% sw in this viewport, which is about 0.42-0.43 x screen height.
  - Heights run 24-33% sh.
  - No dimming of the world behind.
- **Outer frame:** near-black outline about 3 px, corner radius about 6-8 px.
- **Header bar**
  - Full width, about 5% sh tall.
  - Two flat bands (lighter upper about 45%, deeper lower about 55%) plus a dark line under it.
- **Header icon:** at the left, about header height, slightly overlapping the left and top edges, tilted about 10-15 degrees.
- **Title:** white, left-aligned after the icon, about 3% sh, dark outline about 3 px, title case.
- **Close button**
  - Red square at the header's right end, side about equal to header height. In one frame it pokes a few px above and right of the header.

  - Fat white "X" (228,227,232), strokes about 20% of the button width with rounded ends.
- **Body:** black at about 50-60% opacity, so the world shows through and it reads dark brown or olive. Content is inset about 2% of window width.
- **Rows / inner panels:** slightly lighter or darker translucent rectangles with a thin 1 px lighter edge, radius about 4 px.
